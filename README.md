Om een script te runnen MOET je je script in dezelfde directory zetten als je prompt.txt bestand. Daarnaast MOET je een werkende google key hebben in de vorm van een service_account.json file die je ook in diezelfde directory moet hebben.

De prompts zullen in Github verschillende namen hebben. Als je test wilt uitvoeren met het script zal je je txt telkens moeten renamen naar "prompt.txt". Als je dit niet doet kan het script niet de prompt uitlezen.
